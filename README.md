# Premier Remodeling — GitHub Preview V26

This folder is ready to upload directly to a GitHub repository and publish with GitHub Pages.

## What Premier will see

- The complete redesigned website.
- A **Developer Controls** button in the website header.
- An interactive Site Manager with the preview URL and demo key already filled in.
- Page editing, appearance controls, branding, sample Requests, contact testing, media uploads, blog controls, backups, and other management screens.
- Changes made in the preview are saved only in that visitor's browser. They do **not** alter the GitHub repository or the real production website.

This is intentional. GitHub Pages is static hosting and cannot run the private Node backend used by the purchased version.

## Put it online

1. Create a new GitHub repository.
2. Upload **everything inside this folder** to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will show the preview URL after deployment finishes.

Send Premier that URL. They can browse the site and click **Developer Controls** in the header.

## Important

Do not upload the real V24/V23 production package to a public repository. It contains the actual Node backend and private admin system. This V26 folder is the sales-preview build specifically made for GitHub Pages.


## Mobile
The public preview and Developer Controls are responsive. On phones, tap **Menu** at the top of Developer Controls to reach every management section.
